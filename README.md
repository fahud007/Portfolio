# Fahud Ahmmed - Portfolio

A personal portfolio website for **Fahud Ahmmed**, showcasing education, skills, projects, publications and contact information.

## 🚀 Running Locally
The project is a static website, so you can run it using a simple local server.

### Using Python (built-in)
```bash
# Python 3
python -m http.server 8000
```
Then open: http://localhost:8000

## 🗂️ Project Structure
- `index.html` – main page
- `style.css` – styles
- `script.js` – interactive behaviors (theme toggle, menu, typewriter, etc.)
- `assets/` – images, PDF résumé, certificates

## 🛠️ Notes
- Contact form uses EmailJS (configured in `script.js`).
- Theme preference is stored in `localStorage`.
